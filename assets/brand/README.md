# NeuralFence identity

The mark combines a protective shield with four connected nodes forming an **N**. The shield represents security; the connections represent governed AI models, agents and tools.

| Asset | Use |
| --- | --- |
| [neuralfence-mark.svg](neuralfence-mark.svg) | Green mark for light backgrounds |
| [neuralfence-mark-reversed.svg](neuralfence-mark-reversed.svg) | Mint mark for dark backgrounds |
| [neuralfence-wordmark.svg](neuralfence-wordmark.svg) | Full logo with outlined lettering |
| [neuralfence-wordmark-reversed.svg](neuralfence-wordmark-reversed.svg) | Full logo for dark backgrounds |
| [neuralfence-icon.svg](neuralfence-icon.svg) | Square application icon and favicon |

Use the mark at 24px or larger and keep clear space of at least one node diameter around it. Preserve its proportions. The wordmarks contain vector outlines and do not require an installed font.

| Color | Value | Purpose |
| --- | --- | --- |
| Graphite green | `#102827` | Navigation and dark brand surfaces |
| Mint | `#C1F28A` | Logo on dark surfaces and selected navigation |
| Deep teal | `#087F6B` | Primary actions and logo on light surfaces |
| Mist | `#F3F6F3` | Workspace background |
| Ink | `#172C2B` | Main text |

Typography uses **Manrope**. The variable font is distributed under the [SIL Open Font License](OFL-Manrope.txt), sourced from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/manrope). The HTML embeds the font so the prototype works without external font requests.
